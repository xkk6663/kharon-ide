# 日志从未入库：历史重写（2026-11-15）

> 操作类型：破坏性历史重写（`git filter-repo`）。**已执行**。仓库无 remote、从未推送，所以不涉及 force-push 协作问题；代价是**所有提交号变了**。

## 一、之前是什么状态

- `logs\` 在 2026-11-15 白天已经从索引移出并加进 `.gitignore`（提交 `chore(git): 日志不再入库`）；
- 但那只是"以后不再加"，**老提交里仍有 186 个日志 blob**（约 3 MB，最大单条 181 KB）；
- 结论：要"完全不入库、历史里也抹掉"，只能重写历史。

## 二、执行过程

```powershell
# 1) 全量备份（万一失败可整体还原）
git bundle create C:\Users\xiao1\Desktop\zephyr-learn-history-backup-20261115.bundle --all   # 0.8 MB，verify: complete history

# 2) 把用户 WIP 暂存（filter-repo 会 checkout，未提交改动会被覆盖）
git stash push -m "WIP s3_wifi_portal main.c" -- apps/esp32s3/s3_wifi_portal/src/main.c
# 另外单独复制一份 + 记 SHA256，双保险

# 3) 重写：只删 logs/，其它路径一律不动
git filter-repo --force --invert-paths --path logs

# 4) 恢复 WIP 并校验指纹
git stash pop
# main.c SHA256 = 12190A87…5004，与备份一致
```
