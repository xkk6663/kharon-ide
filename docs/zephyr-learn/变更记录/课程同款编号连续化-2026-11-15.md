# 课程同款：编号连续化（2026-11-15）

> **一句话**：`docs\课程同款\` 的九篇不再按"课程课次"编号（`03` / `03b` / `03c` / `03d` / `04`…），改成**按阅读顺序连续编号 00 → 09**；课程线（第三、四课）= 00 → 05，附录 A 与元决策排在 06 之后。

---

## 一、改之前的问题

| 问题 | 具体表现 |
|---|---|
| **空号** | 编到 `03` 就没了 `01` / `02`——那两个号是 Up 主的第一、二课，我们没写对应篇目，于是序号从 00 直接跳到 03 |
| **字母后缀** | 第三课正文之外又长出 `03b` / `03c` / `03d` 三篇（上游板级、加外设、板载清单），排序靠字符串比较，夹在 `03` 与 `04` 之间但语义不属于同一层 |
| **课程线被隔断** | 附录 A（S31 / Korvo-1）专用的两篇（后续需求盘点 `05`、七项实录 `06`）插在第三课与第四课正中间，顺着编号读会在附录材料里绕一圈才回到第四课 |
| **一篇没号** | `课程对照-第三课与本工程.md` 完全没有编号，在资源管理器里排到"课"字后面，容易漏读 |

## 二、新规则

1. **前缀 = 阅读顺序**，整数、连续、无空号、无字母后缀。
2. **两条线分开**：`00–05` 是课程线（第三、四课，主线读者读完就够）；`06` 之后是附录 A（S31 / Korvo-1）与元决策。
3. **课次写进标题**，不靠编号暗示：`02` 的 H1 是"项目结构 与 自定义板级（对应 Up 主「第三课」）"，`05` 是"项目迁移 / 新建 / CMake 缓存 / 按键输入（对应 Up 主「第四课」）"。加新篇时只需往后接号，不用再想"它属于第几课"。
