# 01 · 当前使用的版本

> **现状校准（2026-11-19）**：当前仓库的 Zephyr 树在 `west/zephyr`（west 工作区 `west/`），
> 版本仍是 `4.5.99`；环境变量不再由旧 `env.ps1` 维护，改用 `kharon env` 生成
> `scripts/kharon-env.ps1`。本章的版本事实与旧实测一致，只有位置/环境入口更新。

这本教程只跑**一个版本**，不比较版本线。你把下面这套版本对上，后面每一章的输出都能和书里一致。

| 项 | 值 |

| Zephyr 版本号 | `4.5.99`（`VERSION` 文件里是 4 / 5 / 99 / 0，`EXTRAVERSION` 空） |
| 源码 commit | `34e025569cbb`（完整 `34e025569cbb27660b71db809627c3a7402e2111`） |

`4.5.99` 是"基于 4.5 线、比最新 release 更新一点"的编号，说明这套源码**跟着 main 走**，不是某个 release tag。这一点很重要，因为它决定了本书的板级支持从哪来：

- **ESP32-S3**：主干自带（`boards\espressif\esp32s3_devkitc\`），本书主线；
- **ESP32-S31**：主干没有，靠工作区里已打上的未合并 PR `#119851`（`soc\espressif\esp32s31\` + `boards\espressif\esp32s31_function_coreboard\`），见**附录 A**。

## 版本号会出现在哪些地方（看到别慌）

| 位置 | 长什么样 | 说明 |
|---|---|---|
| 启动横幅 | `*** Booting Zephyr OS build 34e025569cbb ***` | 打印的是 commit 短哈希，不是 4.5.99 |
| `kernel version` 命令 | `Zephyr version: 4.5.99` | shell 里查 |
| 编译目录 `zephyr\.config` | `CONFIG_...` 一大堆 | 与版本相关的开关都在这 |
| 驱动 API | `api->version` | 驱动结构体里的版本字段，跨版本会变 |

## 这本书里唯一"跟版本有关"的两个写法

1. **不写死 ADC 位宽**。S31 是 17 位、S3 是 12 位，代码里从 17 往下探测（`applications\esp32s31\korvo_apps\src\main.c` 的 `adc_probe_read()`），换板不用改代码。
2. **不抄网上的 `CONFIG_` 名字**。先在自己的树里确认符号存在：

```powershell
Select-String -Path C:\Users\xiao1\Desktop\ELAB\kharon-ide\west\zephyr\**\Kconfig* -Pattern "CONFIG_XXX" -SimpleMatch
```

找不到就是这个名字在当前树里不存在，不是"配置没生效"。
