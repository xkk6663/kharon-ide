## 维护约定

- 这一层**不放教程步骤**，也不放一次性调试记录（那些进 `..\..\logs\`）。
- 每篇开头写清"核查日期"（如"2026-11 核查"）：Zephyr 主线在动，结论会过期。
- 事实性文档改动请标注依据来源（源码文件 + 行号，或串口原文），没有依据的判断不写进这一层。
- 与"当初为什么这么定"相关的决策，进 `变更记录\`，不进这里。
